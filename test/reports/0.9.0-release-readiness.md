## 稳定版门禁

1. `termuxpro-version.properties` 必须为 `0.9.0` / `90004`，且发布说明文件存在。
2. 稳定版 `versionCode=90004` 必须高于 `0.9.0-rc.3` 的 `90003`。
3. `git diff --check` 必须通过。
4. `./scripts/validate-skills.sh` 必须通过。
5. `./test/version-metadata-test.sh` 必须通过。
6. `./test/workflow-trigger-policy-test.sh` 必须通过。
7. `./test/release-apk-device-smoke-test.sh` 和 `./test/release-abi-gate-test.sh` 必须通过。
8. 稳定准备分支 PR 合入 `dev` 前，分支 CI 必须通过，并等待合入 `dev` 后收尾 CI。
9. `dev → master` 发布 PR 的 CI 必须通过。
10. `v0.9.0` 稳定标签必须指向 `master` 合并提交，Release workflow 必须完成签名 APK 构建、覆盖升级、
    运行时冒烟和 GitHub Release 创建。

- rc.3 已修复 rc.2 的发布门禁失败，当前没有启动崩溃、安装失败、无法 SSH 或数据损坏阻断证据。
