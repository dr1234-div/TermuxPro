## 冻结范围

- PR #192：深色产品页弹窗防线，统一增值页 AlertDialog/列表样式并补静态门禁。
- PR #194：自动研发 PR 合并流程改用 Pulls merge API，避免等待自身检查导致失败/超时噪声。
- PR #195：SSH 目标粘贴输入容错，统一标准化常见 SSH 地址和命令格式。
- PR #196：AI CLI 会话中心显式启动入口，提供 Claude/Codex 新建与历史入口，固定 `ssh_only`。
- PR #197：AI 后 Git 检查入口，从 AI 会话中心直达结构化 Git 工作台概览。

## 增值服务准入

- 分类：远程工作区、AI CLI、Git/tmux 可视化、移动端工作流效率和上下文工具箱。
- 非目标：不研究、不重写 Termux 原始终端、PTY、包管理、本地 shell、基础会话、基础快捷键或基础文件
  能力。
- 风险控制：AI 历史入口不自动恢复最近会话；AI 启动不自动进入 tmux；Git 检查走结构化工作台而非当前
  shell 注入；SSH 粘贴解析只提取目标参数，不执行粘贴命令。
