# TermuxPro 0.9.4-rc.1 候选发布评审记录

日期：2026-09-01

候选状态：`READY`。`dev` 自 `0.9.3` 稳定版后已有通过门禁的用户可见增值改动，适合冻结为
`0.9.4-rc.1` 候选体验版。

## 冻结范围

- PR #173：明确增值服务边界，Termux 原始能力只做兼容守护和“不受影响”回归。
- PR #174、#175：快捷指令模板引导与验收证据。
- PR #176、#177：AI CLI 启动上下文防误入与验收证据。

## 增值服务准入

- 分类：自定义快捷指令、AI CLI、远程工作区、移动端工作流效率、上下文工具箱和发布流程稳定性。
- 非目标：不研究、不重写 Termux 原始终端、PTY、包管理、本地 shell、基础会话、基础快捷键或基础文件
  能力。
- 风险控制：模板不自动执行；AI 历史入口不自动恢复最近会话；发布流程不覆盖、不移动既有标签。

## 候选门禁

- 本地版本、Skill、workflow、GitHub CLI 和 pre-push 冒烟必须通过。
- GitHub 分支 CI 必须通过。
- GitHub Emulator UI 必须通过。
- Release workflow 必须先完成待发布签名 APK 覆盖升级验收，再创建公开 Pre-release。
- 发布后必须核验 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt` 附件齐全。

## 当前验收记录
