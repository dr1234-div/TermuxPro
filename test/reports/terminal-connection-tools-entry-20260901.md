# 终端工具箱连接与安全入口验收记录（2026-09-01）

## 用户问题

用户主要在终端里 SSH 到服务器使用 Codex CLI/Claude Code。连接异常、远端环境异常或 SSH 公钥处理
发生在同一条开发旅程中，不应要求用户返回首页再找“环境诊断”或“SSH 密钥”。

## 范围

- 终端工具箱新增“连接与安全”分组。
- 增加“环境诊断”入口，复用当前活动工作区打开 `ConnectionDiagnosticActivity`。
- 增加“SSH 密钥”入口，复用当前活动工作区打开 `SshKeysActivity`。
- 无活动工作区或配置无效时失败关闭，只展示可读提示。

## 安全边界

- SSH 密钥页只读取/复制公钥，不读取、不展示、不复制私钥。
- 环境诊断仍执行既有只读诊断命令。
- 不向当前 shell 注入诊断、密钥或文件命令，不影响原始 Termux 终端手动能力。

## 验收重点

- 入口分组语义清晰，连接/安全能力不混入 AI 授权操作。
- 当前工作区是唯一上下文来源，避免误诊断或误安装到错误服务器。
- 本地回归覆盖导航、菜单信息架构、无效工作区恢复和推送前冒烟映射。
