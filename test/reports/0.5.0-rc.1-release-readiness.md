# TermuxPro 0.5.0-rc.1 发布评审记录

## 当前结论

候选版状态：`PUBLISHED`。`dev` 自 `v0.4.0` 后已有多项用户可见体验改动，符合进入候选版冻结的条件。
冻结范围只包含首页入口、终端工具箱、tmux 会话列表上下文和设置页视觉语义修复；没有并入 P2 或额外新功能。

- PR #55/#56：首页信息架构瘦身与工具箱入口显性化，以及对应验收证据。

## 发布门禁

1. `termuxpro-version.properties` 必须为 `versionName=0.5.0-rc.1`、`versionCode=50001`，高于 `0.4.0`。
2. 本地 `TERMUXPRO_USE_CHINA_MIRROR=1 ./scripts/test-all.sh && git diff --check` 必须通过。
3. release PR head 的完整 CI 与 Emulator UI 必须通过。
4. release PR 合入 dev 后，merge commit 收尾 CI 必须通过。
5. 标签 `v0.5.0-rc.1` 必须指向 release PR 合入后的 dev merge commit。
6. Release 工作流必须先完成待发布签名 APK 覆盖升级验收，再创建 GitHub Pre-release。
7. Release 必须非 Draft、标记为 Pre-release，并包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。

无阻断问题后推进 `dev → master` 与 `0.5.0` 稳定版。
