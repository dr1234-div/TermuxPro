# TermuxPro 0.6.0-rc.3 发布评审记录

## 当前结论

候选版状态：`RELEASED_RC`。`v0.6.0-rc.1` 和 `v0.6.0-rc.2` 均已保留失败证据且未创建公开 Release。
本轮递增到 `0.6.0-rc.3`，不覆盖既有候选标签；`v0.6.0-rc.3` 已完成公开 GitHub Pre-release。

## 冻结范围

- PR #69：支持从远端跟踪分支创建本地跟踪分支并切换。
- PR #70：统一 Git 工作台弹窗可读性。
- PR #72：提升多工作区入口可发现性，单工作区时不展示伪选择器。
- PR #73：支持新建本地分支并切换。
- PR #74：Git 概览拆分已暂存/未暂存状态，并支持暂存全部/取消暂存全部。
- PR #76：修复 Release 模拟器验收 ABI 不匹配；公开 APK 保持 arm64，模拟器门禁使用同签名 x86_64 APK。
- PR #78：补齐干净 worktree 构建基线验收 APK 时缺少 `:app:downloadBootstraps` 的发布门禁缺陷。

## 失败复盘

- `0.6.0-rc.1`：Release run `33412664689` 在覆盖升级验收失败。根因是把 `arm64-v8a` APK 安装到 GitHub
  x86_64 模拟器。
- `0.6.0-rc.2`：Release run `33415968260` 在构建 x86_64 基线验收 APK 时失败。根因是稳定标签隔离
  worktree 中未先下载 bootstrap，NDK 编译 `termux-bootstrap-zip.S` 找不到 `bootstrap-aarch64.zip`。

## 本地证据

- PR #78 本地 `TERMUXPRO_USE_CHINA_MIRROR=1 ./test/release-abi-gate-test.sh` 已通过。
- PR #78 本地 `TERMUXPRO_USE_CHINA_MIRROR=1 ./scripts/test-all.sh && git diff --check` 已通过。
- PR #78 GitHub CI、Emulator UI 和 dev merge commit 收尾 CI 均已通过。
- GitHub check suite 诊断仍显示仓库自身 Actions 无风险；`vercel`、`4everland`、`cursor` 的 queued 0 job
  外部空检查未被设为必需检查，属于页面噪声。

## 发布门禁

1. `termuxpro-version.properties` 必须为 `versionName=0.6.0-rc.3`、`versionCode=60003`，高于前序候选包。
2. 本地 `TERMUXPRO_USE_CHINA_MIRROR=1 ./scripts/test-all.sh && git diff --check` 必须通过。
3. release PR head 的完整 CI 与 Emulator UI 必须通过。
4. release PR 合入 dev 后，merge commit 收尾 CI 必须通过。
5. 标签 `v0.6.0-rc.3` 必须指向 release PR 合入后的 dev merge commit。
6. Release 工作流必须先校验公开 arm64 APK，再从稳定标签构建 x86_64 基线验收 APK，并用当前候选
   x86_64 APK 完成覆盖升级与启动冒烟，最后创建 GitHub Pre-release。
7. Release 必须非 Draft、标记为 Pre-release，并包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
