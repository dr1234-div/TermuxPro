## 稳定版发布门禁

1. 本地 `TERMUXPRO_USE_CHINA_MIRROR=1 ./scripts/test-all.sh && git diff --check` 必须通过。
2. 稳定版元数据 PR 的完整 CI 与 Emulator UI 必须通过。
3. 稳定版元数据 PR 合入 `dev` 后，merge commit 收尾 CI 必须通过。
4. 创建 `dev → master` 发布 PR；发布 PR 的完整 CI 与 Emulator UI 必须通过。
5. 发布 PR 合入 `master` 后，在 `master` 合并提交创建不可覆盖标签 `v0.5.0`。
6. Release 工作流必须先完成正式签名 APK 覆盖升级验收，再创建 GitHub Stable Release。
7. Release 必须非 Draft、非 Pre-release，并包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
8. 稳定 Release 完成后，`dev` 必须对齐 `master` 发布提交并等待收尾 CI 成功。

## 发布结论

进入 `dev → master` 稳定发布流程。若任一门禁失败，停止发布并记录失败证据；不得覆盖既有候选标签或稳定标签。
