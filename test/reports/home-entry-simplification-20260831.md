# 首页入口瘦身与工具箱显性化评审记录

## 用户问题

0.2.0 体验反馈显示首页曾堆叠 Git、远程文件、项目任务、后台任务、SSH 密钥和 Web 预览等低频控件；
用户真正高频动作是打开远程 SSH 终端并进入 Codex CLI / Claude Code。过多首页控件会迫使用户理解
不必要功能，也让“管理工作区”这类概念显得不明确。

终端页也存在工具入口可发现性问题：纯图标入口容易被误解，不如直接显示“工具箱”。

## 本轮产品决策

- 首页只承担连接路径：安装 SSH 组件、配置服务器与项目、打开远程终端。
- 低频工具继续保持按需工具箱，不回流首页。
- “管理工作区”改为“连接配置”，表达对象是 SSH 地址、项目目录和连接策略。
- “连接远程工作区”改为“打开远程终端”，表达用户实际动作。
- 终端工具入口从纯图标改为文字按钮“工具箱”，减少猜测成本。

## 验收标准

1. 未安装 SSH 时首页只展示安装 SSH 组件，不展示低频工具卡片。
2. 已配置工作区后，首页展示服务器/项目摘要和连接配置入口，不展开主机、端口、tmux 策略等编辑控件。
3. Git、远程文件、项目任务、tmux、SSH 密钥和 Web 预览不以卡片形式平铺在首页。
4. 终端页工具入口必须有可见文字“工具箱”，且触控高度不低于 48dp。
5. 中文和默认英文资源都同步新概念，避免非中文环境保留旧信息架构。

## 当前证据

- 新增 Robolectric 用例验证已配置首页隐藏低频工具卡片、隐藏连接编辑控件，并使用“连接配置”文案。
- 更新终端布局用例，验证“工具箱”文字与无障碍描述一致，触控高度满足 48dp。
- 待 GitHub CI 与模拟器默认/200% 字体截图验证后更新为完成。
