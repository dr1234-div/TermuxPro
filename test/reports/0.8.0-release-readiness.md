## 稳定版门禁

1. `termuxpro-version.properties` 必须为 `0.8.0` / `80002`，且发布说明文件存在。
2. 稳定版 `versionCode=80002` 必须高于 `0.8.0-rc.1` 的 `80001`。
3. `./scripts/validate-skills.sh` 必须通过。
4. `git diff --check` 必须通过。
5. `./test/version-metadata-test.sh` 必须通过。
6. `./test/terminal-touch-scrollback-test.sh` 必须通过。
7. `./test/workflow-trigger-policy-test.sh` 必须通过。
8. `./test/dialog-readable-style-test.sh`、`./test/release-apk-device-smoke-test.sh` 和
   `./test/release-abi-gate-test.sh` 必须通过。
9. `dev_stable080_20260901 → dev` PR 的 CI 与 Emulator UI 必须通过，并等待合入 `dev` 后收尾 CI。
10. `dev → master` 发布 PR 的 CI 与 Emulator UI 必须通过。
11. `v0.8.0` 稳定标签必须指向 `master` 合并提交，Release workflow 必须完成签名 APK 构建、覆盖升级、
    运行时冒烟和 GitHub Release 创建。

## P0/P1 裁定

- 终端触摸滚动缺陷已被补强到非鼠标来源默认 scrollback，并有 JVM 与脚本级回归锁定。
- Git 本地分支删除只使用 `git branch -d`，不 force、不删除远端、不推送；当前分支、缺失分支和未合并
  分支均失败关闭。
- 工作区上下文和最近状态只改变本地 UI 状态表达，不改变 SSH 主机密钥、认证、tmux 策略或远端执行逻辑。
- 候选发布自动化、候选分支 CI、Emulator UI、Release workflow 和 dev 收尾 CI 已通过；未发现新的启动
  崩溃、不可安装、无法升级、无法 SSH 或真实 tmux 安全回归证据。
