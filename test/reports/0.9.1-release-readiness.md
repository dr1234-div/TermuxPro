## 稳定版门禁

1. `termuxpro-version.properties` 必须为 `0.9.1` / `90102`，且发布说明文件存在。
2. 稳定版 `versionCode=90102` 必须高于 `0.9.1-rc.1` 的 `90101`。
3. `git diff --check` 和 `./scripts/validate-skills.sh` 必须通过。
4. `./test/version-metadata-test.sh`、`./test/workflow-trigger-policy-test.sh`、`./test/release-apk-device-smoke-test.sh`
   和 `./test/release-abi-gate-test.sh` 必须通过。
5. 稳定准备分支 PR 合入 `dev` 前，分支 CI 与适用门禁必须通过，并等待合入 `dev` 后收尾 CI。
6. `dev → master` 发布 PR 的 CI 必须通过。
7. `v0.9.1` 稳定标签必须指向 `master` 合并提交，Release workflow 必须完成签名 APK 构建、覆盖升级、
   运行时冒烟和 GitHub Release 创建。
8. 稳定 Release 必须是非草稿、非预发布，附件包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
9. 稳定 Release 完成后必须将 `dev` 对齐 `master` 并等待收尾 CI。

## P0/P1 裁定

- 本轮稳定版只发布候选版已验证范围，不新增 SSH、tmux、Git 或 AI CLI 行为。

- 当前没有启动崩溃、安装失败、无法 SSH、误杀 tmux、数据损坏或 Release 产物不可安装证据。
