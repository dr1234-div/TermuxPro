# TermuxPro 0.7.1-rc.1 候选版发布评审记录

## 当前结论

候选版状态：`RELEASED_RC`。`dev` 自 `v0.7.0` 后已有用户可见体验修复，且没有新增 SSH/tmux/Git
危险写操作。`v0.7.1-rc.1` 已完成候选发布、正式签名 APK 覆盖升级和 Android 运行时冒烟；允许用户下载
候选包重点体验深色弹窗可读性、终端触摸滚动和“服务器与项目”入口语义。

## 冻结范围

- PR #95：加强终端触摸 scrollback 防回归门禁。
- PR #96：统一 TermuxPro 深色弹窗可读样式。
- PR #97：将首页/终端返回入口文案明确为“服务器与项目”。

## P0/P1 裁定

- 本轮直接回应用户真实体验反馈：`0.5.0` 终端滑动无法阅读历史输出、部分页面深色主题文字不可读、
  首页入口语义不清。
- 触摸滚动本身已在 `0.5.1+` 修复，本候选版增加更严格门禁，避免后续退化。
- 深色弹窗改动覆盖工作区、终端、URL 选择、SSH 密钥、项目任务、自定义指令和 bootstrap 错误等路径，
  不再只修单个截图页面。
- 工作区入口文案只改变用户理解成本，不改变 SSH/tmux 策略和持久化数据结构。
- 未新增高风险远端命令，不触碰真实 tmux server，不改变签名或包名策略。

1. `termuxpro-version.properties` 必须为 `0.7.1-rc.1` / `70101`，且发布说明文件存在。
2. `./scripts/validate-skills.sh` 必须通过。
3. `git diff --check` 必须通过。
4. `./test/terminal-touch-scrollback-test.sh` 必须通过。
5. `./test/dialog-readable-style-test.sh` 必须通过。
6. `./test/version-metadata-test.sh`、`./test/workflow-trigger-policy-test.sh`、
   `./test/release-apk-device-smoke-test.sh` 和 `./test/release-abi-gate-test.sh` 必须通过。
7. `dev_release071Rc1_20260831 → dev` PR 的 CI 与 Emulator UI 必须通过。
