# TermuxPro 0.8.0-rc.1 候选版发布评审记录

## 当前结论

候选版状态：`RC_RELEASED`。`dev` 自 `v0.7.1` 后已有多项用户可见改动，并包含新的 Git 本地写操作
入口；已冻结并发布为 `0.8.0-rc.1` 候选包，供用户体验和发布门禁验证。当前没有证据显示存在未关闭
P0/P1 阻断候选发布。

## 冻结范围

- PR #103：工作区选择器展示工作区名称、服务器和项目目录。
- PR #104：工作区选择器展示最近打开/验证/失败等状态，并区分“打开终端”和“SSH 已验证”。
- PR #105：补强终端触摸滚动策略，非鼠标来源默认滚动 scrollback。
- PR #106：Git 工作台支持安全删除本地非当前分支。

## P0/P1 裁定

- 本轮直接回应用户真实体验反馈：多工作区上下文不足、终端滑动阅读历史输出不可靠、Git 工作台缺少
  本地分支生命周期出口。
- Git 删除能力只使用 `git branch -d`，不 force、不删除远端、不推送；当前分支、缺失分支和未合并分支
  均失败关闭，因此可以进入候选验证。
- 工作区状态展示只改变 UI 与本地状态说明，不改变 SSH 主机密钥、认证、tmux 策略或远端执行逻辑。
- 终端触摸滚动补强触及终端交互语义，候选体验需重点确认手机手指滑动不会污染 AI CLI 输入流。
- 当前没有新增 Release 私钥、真实账号、未脱敏日志或默认 tmux `kill-server` 风险。

若候选体验和发布门禁均无 P0/P1，应在同一维护周期推进 `dev → master` 与 `0.8.0` 稳定版。
