2. `versionCode=90101` 必须高于 `0.9.0` 稳定版 `90004`。
3. `./scripts/codex-quota-guard.sh` 必须允许继续。
4. `./scripts/resource-guard.sh` 必须通过，并保持共享服务器低并发策略。
5. `git diff --check` 和 `./scripts/validate-skills.sh` 必须通过。
6. 版本、workflow、GitHub CLI 封装和预推送冒烟静态门禁必须通过。
7. `dev_release091Rc1_20260901 → dev` PR 的 CI 与 Emulator UI 必须通过，并等待合入 `dev` 后收尾 CI。
8. 候选标签 `v0.9.1-rc.1` 必须由自动 PR 流水线在合并提交上创建，不覆盖既有标签。
9. Release workflow 必须完成签名 APK 构建、覆盖升级、运行时冒烟和 GitHub Release 创建。

## P0/P1 裁定

- 本候选版只冻结 TermuxPro 增值服务：远程 AI CLI、tmux/Git 可视化管理和发布治理。
- 不研究、不重做 Termux 原始终端、PTY、包管理、本地 shell、基础会话或基础快捷键。
- 原始终端能力的验收重点是“不受影响”；候选变更失败时必须安全回退到原始终端可用状态。
