## 稳定版门禁

1. `termuxpro-version.properties` 必须为 `0.8.1` / `80102`，且发布说明文件存在。
2. 稳定版 `versionCode=80102` 必须高于 `0.8.1-rc.1` 的 `80101`。
3. `./scripts/validate-skills.sh` 必须通过。
4. `git diff --check` 必须通过。
5. `./test/version-metadata-test.sh` 必须通过。
6. `./test/workflow-trigger-policy-test.sh` 必须通过。
7. `./test/dialog-readable-style-test.sh` 必须通过。
8. `./test/terminal-touch-scrollback-test.sh` 必须通过。
9. `./test/release-apk-device-smoke-test.sh` 和 `./test/release-abi-gate-test.sh` 必须通过。
10. 稳定准备分支 PR 合入 `dev` 前，分支 CI 与 Emulator UI 必须通过，并等待合入 `dev` 后收尾 CI。
11. `dev → master` 发布 PR 的 CI 与 Emulator UI 必须通过。
12. `v0.8.1` 稳定标签必须指向 `master` 合并提交，Release workflow 必须完成签名 APK 构建、覆盖升级、
    运行时冒烟和 GitHub Release 创建。

## P0/P1 裁定

- 本轮稳定版不新增 SSH、tmux、Git 或远端写操作能力，只发布候选版已验证范围。
- 终端触摸滚动仍有真实 ROM 手感采样缺口，但已有默认 scrollback、AI/TUI 显式模式和模拟器 UI/策略回归；
  当前没有阻断稳定版的启动、安装、升级或无法 SSH 证据。
- 本地会话关闭只作用于本地 Termux 会话，不触碰远程 tmux；远程 tmux 仍使用独立归属校验。
- GitHub 自动化治理不隐藏真实 CI、Release、权限或合并后 CI 失败，只减少重复失败提醒和 CLI/API 抖动误报。
