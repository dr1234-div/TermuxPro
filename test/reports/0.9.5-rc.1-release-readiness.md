# TermuxPro 0.9.5-rc.1 候选发布评审记录

日期：2026-09-01

候选状态：`RELEASED`。`dev` 自 `0.9.4` 稳定版后已积累通过门禁的用户可见增值改动，已冻结并发布为
`0.9.5-rc.1` 候选体验版。公开 Pre-release、APK SHA-256、签名证书和 Release run 已完成核验。

## 冻结范围

- PR #183：AI CLI 会话中心，集中展示当前工作区、Claude/Codex 新建与历史选择命令预览和共享账号风险。
- PR #184：Git Stash 工作台，支持保存、查看、应用和删除指定 stash，不提交、不推送、不清空全部 stash。
- PR #185：Git 分支切换安全门禁，脏工作区阻止本地分支切换和远端跟踪分支创建。
- PR #186：Claude 快捷指令模板防误续接，移除 `claude --continue`，区分新建独立会话和历史选择。

## 增值服务准入

- 分类：AI CLI、自定义快捷指令、Git 可视化、远程工作区、移动端工作流效率和上下文工具箱。
- 非目标：不研究、不重写 Termux 原始终端、PTY、包管理、本地 shell、基础会话、基础快捷键或基础文件
  能力。
- 风险控制：AI 历史入口不自动恢复最近会话；Git 写操作都有显式确认和脏工作区门禁；Stash 删除只作用
  于用户选择的 `stash@{N}`；发布流程不覆盖、不移动既有标签。

- 本地版本、Skill、workflow、GitHub CLI 和 pre-push 冒烟必须通过。
- GitHub 分支 CI 必须通过。
- GitHub Emulator UI 必须通过。
- Release workflow 必须先完成待发布签名 APK 覆盖升级验收，再创建公开 Pre-release。
- 发布后必须核验 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt` 附件齐全。
