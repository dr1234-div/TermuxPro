# TermuxPro 0.8.1-rc.1 候选发布评审记录

候选状态：`PUBLISHED`。`dev` 自 `0.8.0` 稳定版后已有多项用户可见改动，且最新研发 PR、模拟器 UI、
`dev` 合并后 CI、Release 签名 APK 构建和模拟器覆盖升级验收均已通过。已按发布规则冻结并发布

4. `git diff --check` 必须通过。

   `./test/workflow-trigger-policy-test.sh` 必须通过。
6. `./test/terminal-touch-scrollback-test.sh`、`./test/terminal-session-actions-test.sh`、
   `./test/ai-launch-decision-copy-test.sh` 和 `./test/dialog-readable-style-test.sh` 必须通过。
7. `dev_release081Rc1_20260901 → dev` PR 的 CI 与 Emulator UI 必须通过，并等待合入 `dev` 后收尾 CI。

9. Release workflow 必须完成签名 APK 构建、覆盖升级、运行时冒烟和 GitHub Release 创建。

## P0/P1 裁定

- 终端滚动、会话侧栏入口和 AI 启动决策均为用户高频路径，进入候选体验范围。
- 会话关闭仅作用于本地 Termux 会话；远程 tmux 仍使用独立归属校验和显式管理，不受本轮本地会话菜单影响。
- 自动化治理变更只减少重复失败噪声，不隐藏真实 CI、Release、权限或合并后 CI 失败。
- 外部 App 空 check suite 当前不是 Actions failure，且 `dev/master` 未配置分支保护必需检查；作为噪声继续观察。
