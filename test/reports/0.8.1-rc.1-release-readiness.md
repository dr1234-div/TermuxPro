# TermuxPro 0.8.1-rc.1 候选发布评审记录

## 当前结论

候选状态：`READY TO PUBLISH`。`dev` 自 `0.8.0` 稳定版后已有多项用户可见改动，且最新研发 PR、
模拟器 UI 和 `dev` 合并后 CI 已通过。按发布规则冻结为 `0.8.1-rc.1`，不继续把已完成体验修复无限堆在

## P0/P1 裁定

- 终端滚动、会话侧栏入口和 AI 启动决策均为用户高频路径，进入候选体验范围。
- 会话关闭仅作用于本地 Termux 会话；远程 tmux 仍使用独立归属校验和显式管理，不受本轮本地会话菜单影响。
- 自动化治理变更只减少重复失败噪声，不隐藏真实 CI、Release、权限或合并后 CI 失败。
- 外部 App 空 check suite 当前不是 Actions failure，且 `dev/master` 未配置分支保护必需检查；作为噪声继续观察。
