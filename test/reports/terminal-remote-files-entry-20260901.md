# 终端工具箱远端文件入口验收记录（2026-09-01）

## 用户问题

TermuxPro 应把增值服务放在终端开发场景中按需调用，首页不应堆低频控件。远端文件已经有结构化页面，
但终端工具箱此前没有入口，用户在 SSH/AI CLI 工作中需要回到首页或工作区页面才能打开，路径不直接。

## 范围

- 在终端工具箱“项目与 Git”分组增加“远端文件”。
- 使用当前活动工作区打开 `RemoteFilesActivity`。
- 工作区缺失或无效时给出可读提示并失败关闭。
- 不向当前 shell 注入 `ls`、`find`、`cat` 等文件命令，不影响原始 Termux 终端手动操作。

## 非目标

- 不实现远端文件写入、删除、上传或同步。
- 不改变 Termux 原始文件能力、PTY、会话和快捷键行为。
- 不绕过 SSH 主机身份、认证和 OpenSSH 配置。

## 验收重点

- 终端工具箱能直接进入远端文件增值页。
- 入口复用当前活动工作区，避免连接到错误服务器或项目目录。
- 菜单信息架构保持清晰，360dp/200% 字体下继续由模拟器矩阵验收。
- 本地回归覆盖导航、菜单、无效工作区恢复和推送前冒烟映射。
