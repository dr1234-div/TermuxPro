## P0/P1 裁定

- 本次冻结范围集中在 Git 工作台同步链路和发布自动化，未新增 SSH/tmux ownership、Claude 共享账号历史、
  终端 PTY 或输入法行为风险。
- Git 写操作均失败关闭：不 force push、不自动 merge/rebase、不丢弃工作树、不覆盖远端分支、不伪造成功。
- `0.5.0` 触摸滑动无法滚动历史输出的问题已在 `0.5.1+` 修复，并由 `test/terminal-touch-scrollback-test.sh`
  回归覆盖；若稳定版复现，进入补丁版本流程。

## 稳定版发布门禁

1. 稳定版元数据 PR 的完整 CI 与 Emulator UI 必须通过。
2. 稳定版元数据 PR 合入 `dev` 后，merge commit 收尾 CI 必须通过。
3. 创建 `dev → master` 发布 PR；发布 PR 的完整 CI 与 Emulator UI 必须通过。
4. 发布 PR 合入 `master` 后，在 `master` 合并提交创建不可覆盖标签 `v0.7.0`。
5. Release 工作流必须先完成正式签名 APK 覆盖升级验收，再创建 GitHub Stable Release。
6. Release 必须非 Draft、非 Pre-release，并包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
7. 稳定 Release 的 `android-runtime.txt` 证据必须非空，并记录设备/系统/ABI/输入法/进程/无崩溃结论。
8. 稳定 Release 完成后，`dev` 必须对齐 `master` 发布提交并等待收尾 CI 成功。

## 发布结论

`v0.7.0` 已完成稳定发布。后续不得覆盖或移动 `v0.7.0` 标签；若用户在正式包中复现启动、覆盖升级、
SSH 主路径、Git 同步安全、触摸滚动或深色文字不可读回归，应进入 `0.7.1` 候选/补丁流程并保留失败证据。
