## 稳定版门禁

1. `termuxpro-version.properties` 必须为 `0.7.1` / `70102`，且发布说明文件存在。
2. 稳定版 `versionCode=70102` 必须高于 `0.7.1-rc.1` 的 `70101`。
3. `./scripts/validate-skills.sh` 必须通过。
4. `git diff --check` 必须通过。
5. `./test/terminal-touch-scrollback-test.sh` 必须通过。
6. `./test/dialog-readable-style-test.sh` 必须通过。
7. `./test/version-metadata-test.sh`、`./test/workflow-trigger-policy-test.sh`、
   `./test/release-apk-device-smoke-test.sh` 和 `./test/release-abi-gate-test.sh` 必须通过。
8. `dev_stable071_20260831 → dev` PR 的 CI 与 Emulator UI 必须通过，并等待合入 `dev` 后收尾 CI。
9. `dev → master` 发布 PR 的 CI 与 Emulator UI 必须通过。
10. `v0.7.1` 稳定标签必须指向 `master` 合并提交，Release workflow 必须完成签名 APK 构建、覆盖升级、
    运行时冒烟和 GitHub Release 创建。

## P0/P1 裁定

- 终端触摸滚动问题已由 `0.5.1+` 功能修复，本版本增加回归门禁，防止再次退化。
- 深色弹窗修复覆盖多个高频路径，不是单点样式修补。
- “服务器与项目”入口只改变文案语义，不改变远程连接配置、tmux 策略或持久化结构。
- 候选版发布后未发现新的启动崩溃、不可安装、无法升级、无法 SSH 或真实 tmux 安全回归证据。
