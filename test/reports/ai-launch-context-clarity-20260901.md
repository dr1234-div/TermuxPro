# AI CLI 启动上下文防误入验收记录

日期：2026-09-01

## 增值服务准入

- 分类：AI CLI、远程工作区、移动端工作流效率。
- 用户问题：手机上从不同入口启动 Claude Code 或 Codex CLI 时，用户需要先确认目标服务器、tmux 和项目目录。
  现有提示展示 active workspace，但终端工具箱入口实际会把命令发送到当前可见终端会话，存在误入错误
  SSH/tmux/目录的风险。
- 非目标：不读取 Claude/Codex 私有历史存储，不重做 Termux 原始终端、PTY、本地 shell 或基础会话能力。
- 安全边界：TermuxPro 仍不自动进入最近 AI 历史会话；历史入口只打开 CLI 原生选择器。

## 本轮交付

- 区分工作台入口和终端工具箱入口的 AI 启动说明。
- 终端工具箱入口明确提示命令会发送到“当前正在显示的终端会话”，要求用户确认 SSH、tmux 和项目目录。
- 新建/历史两个操作项展示即将执行的 CLI 命令，例如 `claude`、`claude --resume`、`codex resume`。

## 验收重点

- 工作台入口继续展示远程目标并创建独立本地终端会话。
- 终端工具箱入口必须额外显示当前可见终端风险提示。
- Claude 共享账号继续默认推荐新建会话。
- 历史会话入口不得自动恢复最近会话。
- 本轮不修改原始 Termux 终端输入、PTY 或基础会话语义。
