# 终端工具箱 Web 预览入口验收记录（2026-09-01）

## 增值服务准入

- 类型：远程开发增值服务。
- 用户价值：开发者在终端内调试 Web 项目时，不需要返回首页即可按需启动本机 loopback SSH 隧道或打开手机浏览器预览；入口文案显式包含 Web 语境，避免误解为普通 SSH 隧道或系统浏览器操作。
- 非目标：不改写 Termux 原始终端、PTY、本地会话、包管理或基础快捷键；不在当前 shell 注入命令。

## 设计与安全

- 入口读取当前活动远程工作区快照，复用已保存的 SSH 目标、远端端口和手机端口。
- 启动隧道时新开 Termux 会话执行 `ssh -N -T -L 127.0.0.1:<手机端口>:127.0.0.1:<远端端口>`，只绑定手机 loopback。
- 打开浏览器只使用 `http://127.0.0.1:<手机端口>`。
- 工作区缺失、SSH 目标非法或预览端口非法时失败关闭，提示用户回工作台配置端口。

## 回归面

- 原始终端当前会话不被写入任何命令。
- 工具箱信息架构保持“项目与 Git”分组，Web 预览作为低频工具按需调用，不回流首页。
- 工作区快照解析新增预览端口，旧配置默认使用 `5173`，非法端口不影响普通 SSH 工作区可用性。

## 自动化证据

- `WebPreviewNavigationTest`：覆盖启动隧道、打开浏览器、非法端口失败关闭。
- `WorkspaceTargetStoreTest`：覆盖活动工作区预览端口读取、旧配置默认值、非法预览端口独立失败。
- `TerminalProjectToolsMenuTest`：覆盖工具箱中 Web 预览入口顺序与中文文案。
- `scripts/pre-push-smoke.sh`：工作区快照与 Web 预览入口变更自动触发上述测试。
