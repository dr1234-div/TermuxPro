# TermuxPro 0.7.0-rc.1 候选版发布说明

`0.7.0-rc.1` 是 Git 工作台操作闭环候选版，重点补齐手机端远程开发中最常用的提交同步链路：
暂存、提交、刷新上游、快进拉取和安全推送。

## 核心变化

- Git 工作台新增“提交已暂存”入口：提交前明确展示已暂存/未暂存范围，只创建本地提交，不自动暂存、
  不推送、不丢弃文件。
- Git 概览展示具体 upstream 名称，并支持“更新远端”：只 fetch 当前 upstream 所属远端，不 merge、
  不 rebase、不修改工作树或 index。
- 新增“快进拉取”：仅在工作树干净、存在 upstream 且当前分支落后时执行 `git pull --ff-only`；
  需要 merge/rebase、无 upstream 或存在未提交文件时失败关闭。
- 新增“推送”：仅对当前分支已配置的 upstream 执行普通非 force push；游离 HEAD 或仍落后 upstream
  时阻止，推送成功后刷新本地远端跟踪状态。
- 发布自动化修复：稳定版证据补录分支不会被误判为候选发布分支，避免稳定版本号触发 RC 自动发布。

## 验收重点

1. 在远程 Git 仓库中打开 Git 工作台，能看到当前分支、upstream、领先/落后数量、已暂存/未暂存数量。
2. 已暂存文件可被提交；未暂存文件不会被本次提交误纳入。
3. “更新远端”只刷新远端状态，不合并、不改写本地工作树。
4. “快进拉取”只在工作树干净且落后 upstream 时可用，执行后 ahead/behind 状态刷新。
5. “推送”只在 ahead>0 且 behind=0 时可用，不 force push；未提交文件不会被推送。
6. 分支落后 upstream、无 upstream 或游离 HEAD 时，相关操作必须失败关闭并给出明确提示。
7. 360dp 深色主题、默认字体和 200% 字体下，Git 工作台按钮、状态和弹窗仍可读、可点击。

## 已知限制

- 本候选版仍不支持按单个文件暂存/取消暂存、stash、冲突解决、远端分支删除或强制推送。
- 推送仅面向已配置 upstream 的当前分支；新建远端分支需要后续单独设计确认流程。
- Git 操作依赖远端项目路径、SSH 认证和服务器上的 Git 可用；认证失败、非 Git 仓库或网络中断会失败关闭。
- 触摸滑动历史输出问题已在 `0.5.1+` 修复；如果在本候选版复现，应重新按 P0 处理。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 该版本是候选版，用于验证 Git 工作台同步链路是否符合真实手机远程开发场景。
