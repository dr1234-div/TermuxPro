# TermuxPro 0.3.0-rc.1 候选版发布说明

这是 `0.3.0` 的首个候选版本，聚焦手机远程开发中的状态理解、入口可发现性和个人工作流扩展。
候选版用于安装体验和运行时回归，不代表稳定版门禁已经全部通过。

## 主要改进

- 新增远程 Git 工作台：直接查看当前分支、修改数量、上游状态、本地/远端分支和最近提交，并可安全切换本地分支。
- 新增按工作区隔离的快捷指令：支持创建、查看、编辑、复制、排序、启停和删除，执行前明确展示服务器、目录与命令。
- 终端顶部常驻“会话”和“工作台”文字入口，降低首次使用时把图标误认成头像的理解成本。
- 会话切换等前台反馈改用应用内可读横幅，避免部分 Android 主题出现白色空提示。
- 连接可信状态增加时效和就地复检，不再把打开终端误报为 SSH 已认证成功。
- 远程工具统一绑定当前工作区目标；失效选择会拒绝执行，不会静默回退到其他服务器。

## 安全边界

- 快捷指令拒绝保存常见密码、Token、私钥和 URL 内嵌凭据；危险命令必须确认。
- Git 分支切换只接受实际查询到的本地分支，脏工作树必须再次确认，不提供强制切换或历史破坏操作。
- 不自动接受 SSH 主机密钥，不保存 SSH 密码或 AI 凭据，不自动进入任意 tmux/AI 历史会话。

## 本候选版自动化证据

- PR #34–#38 的全模块测试、Lint、隔离 SSH/tmux fixture 和模拟器 UI 门禁通过。
- Android 35、360dp、深色主题、简体中文默认字体与 200% 字体截图已覆盖新增入口、Git 工作台和快捷指令。
- 发布标签前仍须重新执行 Release/R8、签名、APK 内容、版本和证书校验。

## 体验重点

1. 从终端顶部能否立即找到会话列表和工作台，不需要返回首页。
2. Git 工作台能否准确展示真实仓库状态，并在脏工作树切换分支前清楚说明风险。
3. 两个不同工作区的快捷指令是否完全隔离，预览目标与实际 SSH 目标是否一致。
4. 新建、编辑、复制、排序、停用和删除快捷指令后，重启应用数据是否保持正确。
5. 会话切换、失败和成功提示在默认/200% 字体及深色主题下是否始终有可读文字。
6. 升级安装后应用名仍为 `TermuxPro`，0.2.0 的工作区配置不丢失。

## 已知限制

- Git 工作台本轮不包含暂存、提交、推送、删除分支、变基或强制重置；这些写操作需要独立安全切片。
- 快捷指令暂不支持云同步、跨设备共享、变量模板和公共指令市场。
- Claude Code 与 Codex CLI 历史会话仍使用各自原生选择器，统一会话元数据中心尚未完成。
- Android 实体设备或云真机上的软键盘、弱网、后台恢复及 OEM 行为仍需按风险矩阵补充证据。

## 安装提醒

- 包名保留为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 卸载应用会删除其私有 Linux 环境和本地配置，升级体验前请备份重要数据。
- 本版本是 Pre-release；需要稳定环境时继续使用 `0.2.0`。
