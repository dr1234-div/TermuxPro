# TermuxPro 0.9.0-rc.1 候选版发布说明

`0.9.0-rc.1` 是 `0.8.1` 之后的候选版本，重点把远程开发中的低频但高价值工具迁入终端内按需工具箱，
减少返回首页和手输命令的打断，同时继续治理 GitHub 自动化失败噪声。

## 核心变化

- 终端工具箱直达 Git 工作台：`Git 状态` 与 `审查 Git Diff` 会复用当前远程工作区打开移动端结构化页面，
  不再向当前 shell 注入原始 Git 命令。
- 终端工具箱直达 tmux 会话中心：用户可以从当前终端显式查看和进入远端 tmux 会话，不自动污染未指定会话。
- 终端工具箱直达项目任务：按当前工作区打开项目任务页，避免在终端里重复输入检测和运行命令。
- 终端工具箱直达远端文件：可从当前远程项目进入文件浏览，不需要回到首页。
- 新增连接与安全工具分组：可从终端打开环境诊断和 SSH 密钥页，排查连接问题时不离开当前工作上下文。
- 新增 Web 预览入口：可从终端工具箱启动仅绑定手机 loopback 的 SSH Web 隧道，或直接打开本机浏览器预览。
- 固化“增值服务优先”准入规则：Termux 原有终端、PTY、包管理、本地 shell 和基础快捷键只作为兼容回归面，
  不作为 TermuxPro 主线研发方向。
- GitHub 自动化继续降噪：文档/规则/报告变更走快速静态门禁；自动 PR 合并后按 merge commit 等待 dev
  收尾 CI，减少“实际成功但流水线等待超时”的失败邮件。

## 验收重点

1. 进入远程终端后，从顶部 `工具箱` 可以找到 Git、tmux、项目任务、远端文件、Web 预览、环境诊断和 SSH 密钥。
2. 这些增值入口不得向当前 shell 写入命令；失败时提示回工作台配置，不影响原始终端继续使用。
3. Web 预览只使用 `127.0.0.1:<手机端口>` 到 `127.0.0.1:<远端端口>` 的 SSH 本地转发，不暴露到局域网。
4. 终端工具箱在 360dp 深色主题、默认字体和 200% 字体下可读、可点击。
5. 研发 PR 的 CI、模拟器 UI、自动合并和 dev 收尾 CI 均成功；候选 Release 必须完成签名 APK 构建与覆盖升级。

## 已知限制

- 本版本仍不解析 Claude Code/Codex 的历史会话元数据；历史选择继续交给 CLI 原生选择器。
- Web 预览入口复用工作区已保存端口，不在终端工具箱内提供临时端口编辑；需要修改端口时回到工作台配置。
- 远端 tmux 会话管理继续遵守归属隔离；归属未知或其他用户会话只允许显式进入，不越权重命名或停止。
- 本地共享服务器不启动模拟器；候选版运行时证据来自 GitHub Actions 隔离模拟器和 Release 工作流。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.8.1` 正式版，可直接覆盖升级到本候选版本。
