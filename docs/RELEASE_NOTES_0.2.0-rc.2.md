# TermuxPro 0.2.0-rc.2 候选版发布说明

这是 `0.2.0` 的第二个候选版本，重点修复远程工具的失败恢复、大字体操作可达性，以及 tmux 会话
归属误判和误停止风险。候选版用于真实设备体验和回归，不代表稳定版验收已经完成。

## 主要改进

- Git、远程目录、文件预览、项目任务、连接诊断等页面统一提供可理解的失败状态和恢复动作。
- 360dp、深色主题和 200% 系统字体下，远程工具页面保留返回、刷新和恢复入口。
- tmux 会话归属不再依据名称前缀，改用工作区随机 owner、目标指纹、服务端 PID、会话 ID 和创建时间联合核对。
- 工作区指纹同时绑定 SSH 主机、端口和项目路径，避免不同目标之间误复用会话。
- 未知归属会话只能由用户显式进入，TermuxPro 不提供停止操作。
- TermuxPro 自有会话的进入与停止在同一个 tmux 命令队列中再次核对身份和归属，防止检查后的同名替换竞态。
- 项目任务会话身份改用 SHA-256，减少名称碰撞和跨工作区混淆。
- 真实 tmux 测试强制使用唯一 `-L` 套接字，清理不会触碰用户正在使用的默认 tmux 服务。

## 本候选版已验证

- 全模块 JVM/Robolectric 测试、Android Lint、Debug APK 和 Android 测试源码编译通过。
- 隔离 SSH/tmux fixture 验证错误 owner 被拒绝、正确 owner 可管理、未知会话不授予停止权限。
- Android 35、360dp、深色主题、简体中文默认字体与 200% 字体截图门禁通过。
- `hdr-TermuxPro日常迭代` 真实会话在本地 tmux 回归前后保持存在。
- Release 构建继续校验包名、版本、Launcher、ARM64 ABI、v1/v2 签名和发布证书。

## 体验重点

1. 升级安装后确认桌面名称仍为 `TermuxPro`，已有工作区配置保持不变。
2. 仅 SSH、列出 tmux、进入指定 tmux、创建或恢复 TermuxPro 会话四种策略分别符合预期。
3. 普通或其他用户创建的 tmux 会话显示为“归属未知”，可以显式进入但不能由应用停止。
4. TermuxPro 创建的会话在应用重启后仍显示为自有会话；若 owner 或工作区指纹变化，管理动作必须拒绝。
5. Claude Code 与 Codex CLI 默认新建安全上下文，历史会话必须由用户显式选择。
6. 在默认字体和 200% 字体下检查工具页面的返回、刷新、失败恢复和软键盘操作。

## 已知限制

- 卸载应用、清除应用数据或删除工作区会移除本地 owner。远端旧会话会安全降级为“归属未知”，应用不会
  自动认领或覆盖其 `@termuxpro_owner`；用户仍可显式进入并自行核实。
- Git 修改和远程文件预览的超长等宽内容仍需横向滚动，后续会继续优化移动端阅读体验。
- SSH alias 外部修改、连接验证 TTL、主机指纹与验证目标绑定仍在后续迭代中。
- Codex/Claude 历史会话目前使用各自 CLI 的原生选择器，尚未提供带项目和时间信息的统一会话中心。
- 本候选版仍需补齐 Android 实体设备或云真机上的真实 SSH、tmux、Claude Code、Codex CLI、软键盘
  和恢复场景验收；设备品牌仅作为兼容性样本，不构成固定发布门禁。

## 安装提醒

- 包名保留为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 卸载已有 Termux 会删除其应用私有 Linux 环境，请先备份重要数据。
- 密码、私钥和 Token 不写入工作区配置，仍由 OpenSSH 或远端环境管理。
