# TermuxPro 0.8.0-rc.1 候选版发布说明

`0.8.0-rc.1` 是 `0.7.1` 之后的候选版本，重点改善多工作区识别、终端触摸滚动和 Git 工作台分支
生命周期。该版本包含新的 Git 本地写操作入口，因此先作为候选包发布，确认没有 P0/P1 后再推进
`0.8.0` 正式版。

## 核心变化

- 工作区选择器展示更多上下文：多工作区时不再只显示抽象名称，会同时显示工作区名称、服务器和项目目录，
  降低误连到错误服务器或错误项目的风险。
- 工作区最近状态更明确：区分尚未验证、最近打开、最近验证、验证过期、需处理、检查失败和状态未知；
  不再把“打开过终端”误报为 SSH 已验证。
- 终端触摸滚动策略补强：所有非鼠标来源的滚动默认进入 scrollback，避免厂商输入栈或兼容路径把手机
  上下滑动退化为命令历史 `DPAD_UP/DPAD_DOWN`。
- Git 工作台支持安全删除本地分支：只列出非当前本地分支，使用 `git branch -d`，不 force、不删除远端；
  未合并分支由 Git 拒绝并保留。

## 验收重点

1. 多工作区选择器能清楚区分服务器、项目目录和最近状态。
2. 手机终端中长输出可用手指上下滑动阅读历史内容，不影响 shell、Codex CLI 或 Claude Code 的输入流。
3. Git 工作台中“删除本地分支”只出现可安全删除的本地分支；当前分支和远端分支不可删除。
4. 删除确认文案明确说明“不删除远端、不 force、未合并会拒绝”，危险按钮颜色可读且不会和普通主操作混淆。
5. 360dp 深色主题、默认字体和 200% 字体下，工作区和 Git 工作台入口仍可读、可触达。

## 已知限制

- 本版本仍不提供远端分支删除、强制删除、stash、按文件暂存或冲突解决。
- 触摸滚动候选验收仍需要在真实手机或可交互 Android 设备上确认手感；模拟器只能证明启动、布局和基础
  输入策略不回归。
- Claude Code 共享账号的会话隔离、tmux 完整 CRUD 与历史会话治理仍在后续迭代范围内。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.7.1` 正式版，可直接覆盖升级到本候选版本。
