# TermuxPro 0.6.0 正式版发布说明

`0.6.0` 是面向手机 SSH 远程开发的 Git 工作台增强正式版。该版本沿用 `0.6.0-rc.3` 已验证的功能冻结
范围，并吸收发布门禁证据修复；不新增未经过候选验证的应用功能。

## 核心变化

- Git 工作台支持从远端跟踪分支创建同名本地跟踪分支并切换；`origin/HEAD` 被过滤，已有本地分支时
  失败关闭。
- Git 工作台新增“新建分支”，从当前 HEAD 创建本地分支并切换，不推送远端、不覆盖已有分支。
- Git 概览新增“已暂存 / 未暂存”文件数拆分，不再只显示一个总改动数。
- Git 工作台新增“暂存全部”和“取消暂存”入口，操作前有确认说明；只修改 Git index，不提交、不推送、
  不执行硬重置，也不丢弃工作区文件。
- 单工作区时首页不再展示只有一个选项的工作区下拉选择器；已配置工作区时提供更直接的新建工作区入口。
- Git 弹窗和列表继续使用 TermuxPro 深色主题，覆盖中文和 200% 字体回归。
- 发布流水线继续校验公开 arm64 APK，同时用 x86_64 门禁 APK 在 GitHub 模拟器上执行覆盖升级验收。
- 发布设备门禁不再允许无崩溃时生成空的 `android-runtime.txt`；后续发布会写入设备型号、Android
  版本、ABI、输入法、进程 PID 和无崩溃结论。

## 验收重点

1. 在远程项目中打开 Git 工作台，能直接看到当前分支、总改动数、已暂存数和未暂存数。
2. 可从本地分支列表切换，也可从远端跟踪分支显式创建本地跟踪分支后切换。
3. 可新建本地分支并切换；非法分支名、已有分支和 Git 失败必须有明确反馈。
4. “暂存全部”只把未暂存/未跟踪文件加入暂存区；“取消暂存”只把 staged 文件移回工作区。
5. 所有 Git 写操作都不会提交、推送、丢弃改动或覆盖已有分支。
6. 360dp、深色主题、默认字体和 200% 字体下，Git 工作台关键状态和操作入口可读、可点击。
7. 正式 Release 必须在公开前完成签名 APK 覆盖升级、启动冒烟和非空运行时证据采集。

## 已知限制

- 本版本仍不提供按单个文件暂存/取消暂存、提交、推送、拉取、stash 或冲突解决；这些高风险动作会按
  独立纵向切片继续推进。
- Git 工作台仍依赖当前工作区已完成 SSH 认证和远端 Git 可用；认证失败或非 Git 仓库会失败关闭并提示。
- TermuxPro 只管理带有匹配 ownership 元数据的自有 tmux 会话，不会接管既有共享 tmux 会话。
- Claude Code 与 Codex CLI 历史会话仍使用各自原生选择器，统一 AI 会话元数据中心尚未完成。
- Android 实体设备或云真机上的软键盘、弱网、后台恢复及 OEM 行为仍需在后续版本继续补充证据。

## 安装提醒

- 包名保留为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 卸载应用会删除其私有 Linux 环境和本地配置，升级体验前请备份重要数据。
- 如果你已经安装 `0.5.1` 正式版或 `0.6.0-rc.3` 候选版，可直接覆盖升级到本正式版。
