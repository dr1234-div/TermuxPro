# TermuxPro 0.9.6-rc.1 候选版发布说明

`0.9.6-rc.1` 是 `0.9.5` 之后的候选体验版，冻结范围只包含 TermuxPro 增值服务改进：
SSH 远程工作区输入容错、AI CLI 会话中心行动化、AI 后 Git 检查入口、深色弹窗防线和自动 PR 稳定性。

本版本不研究、不重做 Termux 原始终端、PTY、包管理、本地 shell、基础会话、基础快捷键或基础文件能力；
这些能力仅作为“不被增值层破坏”的兼容回归面。

## 主要变化

- SSH 目标输入支持从手机直接粘贴常见格式：`user@host`、`user@host:port`、`ssh -p port user@host` 和
  `ssh://user@host:port/path`；保存、连接、Git、tmux、文件、诊断、SSH Key 和 Web 预览统一标准化目标。
- AI CLI 会话中心从说明页升级为行动中心：直接提供 Claude/Codex 新建与历史入口，历史入口只打开 CLI
  原生选择器，不读取私有历史，也不自动进入最近会话。
- AI 会话中心新增“查看 Git 改动”：用户在 Claude/Codex 修改代码后，可直接进入结构化 Git 工作台概览，
  不需要回首页或在终端里手写 `git status`。
- 深色产品页弹窗进一步统一为 TermuxPro 样式，并增加静态门禁，防止系统默认黑字/浅色列表在深色页面
  中再次出现。
- 自动研发 PR 合并流程避免等待自身检查，减少成功合并后仍出现失败/超时邮件的噪声。

## 验收重点

1. 粘贴 SSH 目标后必须只产生规范化 host/port/path，不执行粘贴内容中的额外命令。
2. AI CLI 会话中心启动 Claude/Codex 时必须打开独立 SSH 终端，并固定普通 `ssh_only` 策略，不自动进入、
   创建或恢复 tmux。
3. Claude 共享账号场景下默认新建会话；历史选择只进入 Claude 原生选择器。
4. “查看 Git 改动”只能打开结构化 Git 工作台，不能向当前 shell 注入 Git 命令。
5. 深色弹窗、列表项、标题、正文和按钮在 360dp 默认/200% 字体下保持可读。
6. 原始 Termux 终端、PTY、本地 shell、基础会话和基础快捷键语义不得被 TermuxPro 增值层修改。

## 已知限制

- 本候选版仍不读取 Claude/Codex 内部历史文件；历史列表由 CLI 原生选择器负责。
- Git 工作台不替代完整 Git 客户端，仍以移动端高频安全操作为主。
- 本地共享服务器 KVM 不可用，候选 APK 的覆盖升级与截图验收依赖 GitHub Runner 模拟器。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.9.5` 正式版，可直接覆盖升级到本候选版本。
