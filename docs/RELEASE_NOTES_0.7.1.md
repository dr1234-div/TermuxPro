# TermuxPro 0.7.1 正式版发布说明

`0.7.1` 是 `0.7.0` 之后的体验补丁稳定版，来自已发布并通过门禁的 `0.7.1-rc.1` 候选范围。
本版本不新增 SSH/tmux/Git 写操作能力，重点修复手机终端体验和深色界面可读性。

## 核心变化

- 终端触摸滚动回归门禁加强：明确锁定手机手指上下滑动必须滚动历史输出，不得退化为命令历史
  `DPAD_UP/DPAD_DOWN`。
- 深色弹窗可读性统一：工作区、终端、URL 选择、SSH 密钥、项目任务、自定义指令和 bootstrap 错误等
  高频弹窗统一使用 TermuxPro 深色背景、标题、正文、按钮和列表项颜色，减少厂商默认主题导致的黑字或
  浅字不可读问题。
- 首页/终端返回入口文案从抽象的“连接配置”进一步收敛为“服务器与项目”，更准确表达它管理 SSH 地址、
  项目目录、连接策略和远程入口。

## 验收重点

1. 360dp 深色主题、默认字体和 200% 字体下，弹窗标题、正文、按钮、列表项和输入框可读。
2. 终端页内搜索、AI 确认、命令确认、URL 选择、最大会话数提示等弹窗不再依赖系统默认黑/白文字。
3. 工作区首页已配置状态下，入口显示“服务器与项目”，用户能理解该入口用于维护服务器和项目目录。
4. 触摸滑动继续滚动 scrollback；鼠标滚轮和显式键盘翻页保留既有语义。

## 已知限制

- 该版本不新增真机专属修复；厂商 ROM、输入法和弱网场景仍需后续设备矩阵补证据。
- Git 工作台仍不支持按文件暂存、stash、冲突解决或新建远端分支。
- tmux 与 Claude/Codex 历史会话的完整安全管理仍在后续迭代范围内。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.7.0` 正式版，可直接覆盖升级到本版本。
