# TermuxPro 0.2.0-rc.1 候选版发布说明

这是 `0.2.0` 的首个候选版本，重点验证手机端远程开发的安全连接、状态驱动首页、tmux 会话隔离与
Claude Code/Codex CLI 工作流。候选版用于真实设备体验和回归，不代表稳定版验收已经完成。

## 主要改进

- 首页按未配置、已配置和已验证状态渐进展示，每个状态只保留当前最重要的操作。
- 已保存工作区默认只展示摘要，连接参数与低频管理动作按需展开，删除不再常驻首页。
- 默认仅建立 SSH 连接，不会擅自进入其他用户或未知归属的 tmux 会话。
- 工作区可独立选择仅 SSH、新建独立 tmux、进入指定 tmux 或选择 tmux 会话。
- Claude Code 与 Codex CLI 明确区分“新建安全会话”和“选择历史会话”，不会静默恢复全局最近会话。
- 修改主机、端口、目录、tmux 策略或会话名后，旧的连接验证状态立即失效。
- 修复桌面应用名称，Launcher 始终显示 `TermuxPro`。
- 改进深色主题文字对比度、360dp 页面布局和 200% 系统字体适配。
- 增加简体中文默认字体/200% 字体模拟器截图门禁，以及隔离 SSH/tmux 真实 fixture。
- 统一版本配置、正式签名构建、标签校验和 GitHub Release 自动发布流程。

## 本候选版已验证

- 全模块 JVM/Robolectric 测试、Android Lint 和 Debug APK 构建通过。
- Android 35、360dp、深色主题、简体中文默认字体与 200% 字体共 24 张截图门禁通过。
- 首页未配置、连接说明、连接已验证、策略选择和 AI 会话选择关键状态已完成视觉复核。
- Release 构建会继续校验包名、版本、Launcher、ARM64 ABI、v1/v2 签名和发布证书。

## 体验重点

请重点验证以下真实使用路径：

1. 输入或选择 SSH 工作区后，仅连接服务器，不自动进入未知 tmux 会话。
2. 查看 tmux 会话列表并显式进入指定会话；未知归属会话不能被误停止。
3. 分别启动 Claude Code、Codex CLI 新会话和历史会话选择器。
4. 使用手机软键盘输入、切换前后台、锁屏恢复和网络断开重连。
5. 在默认字体和较大系统字体下检查首页、终端顶栏、会话选择和工具页面可读性。

## 已知限制

- Git 修改和远程文件预览的超长等宽内容仍需横向滚动，后续会继续优化移动端阅读体验。
- SSH alias 外部修改、连接验证 TTL、主机指纹与验证目标绑定仍在后续迭代中。
- Codex/Claude 历史会话目前使用各自 CLI 的原生选择器，尚未提供带项目和时间信息的统一会话中心。
- 本候选版仍需补齐 Android 实体设备或云真机上的真实 SSH、tmux、Claude Code、Codex CLI、软键盘
  和恢复场景验收；设备品牌仅作为兼容性样本，不构成固定发布门禁。

## 安装提醒

- 包名保留为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 卸载已有 Termux 会删除其应用私有 Linux 环境，请先备份重要数据。
- 密码、私钥和 Token 不写入工作区配置，仍由 OpenSSH 或远端环境管理。
