# TermuxPro Android 真机验收清单

## 测试前提

- 主测：三星测试机，ARM64，启用开发者选项和 USB 调试。
- 兼容确认：小米 17 由用户做最终冒烟，不要求交出主力机。
- 因包名为 `com.termux` 且使用项目独有签名，安装前需要备份并卸载其他签名来源的 Termux
  及其插件。
- 只安装 `release_arm64-v8a.apk`，记录 APK SHA-256 和设备系统版本。
- 单设备连接后可先执行 `scripts/device-smoke-test.sh`，自动完成覆盖安装、启动、前台 Activity 和启动崩溃检查；脚本不会自动卸载已有应用。
- 当前远程开发机未安装 Android 模拟器/系统镜像，且尚无 ADB 真机连接；不在共享机器上下载或启动高内存模拟器，运行时最终证据由三星测试机补齐。
- JVM 冒烟会在生产主题和简体中文资源下逐页膨胀 9 个自定义布局；该检查用于提前捕获无效 Drawable、缺失 View 类和主题属性，但不能替代真机渲染检查。

## P0 冒烟

1. 全新安装后启动到中文工作区首页，无崩溃或黑屏。
2. 点击“安装 SSH 连接组件”，完成 bootstrap 和 OpenSSH 安装。
3. 新增两个工作区，切换、保存、重启 App 后数据仍正确。
4. 首次连接显示真实 SSH 主机指纹确认，不自动接受。
5. 密码和密钥认证各完成一次；工作区配置中不出现密码字段。
6. 首连终端只有在认证成功且进入目标目录后显示 `SSH authenticated`；路径不存在时明确提示并降级到普通远端 Shell。
7. 在连接诊断中分别构造 DNS 失败、超时、拒绝、无路由、指纹未确认/变化和认证失败，确认每种情况显示唯一且可操作的中文原因。
8. 新工作区保持“仅 SSH”默认策略，确认连接不探测、不创建、不进入任何 tmux；Claude Code 和 Codex CLI 均启动新上下文，不执行全局最近会话恢复。
9. 依次验证“查看列表但不进入”“仅进入指定会话”“创建或进入指定会话”；不存在的指定会话不得误入其他会话，“仅进入”不得隐式创建。
10. 打开“检查远端开发环境”，确认系统、项目目录、tmux、Git、Node.js、Java、Claude Code、Codex CLI 的可用状态与服务器一致。
11. 使用软键盘输入 300 个以上中文字符，验证多行编辑、粘贴、取消草稿和发送。
12. 验证 ESC、TAB、CTRL、方向键、Ctrl+C，以及 Git 状态、Diff 和项目检查入口。
13. 在同一仓库分别制造未暂存、已暂存和未跟踪文件，确认原生审查页正确区分前两类，且只列出未跟踪文件名。
14. 验证远端文件浏览的空格/Tab/换行文件名、空文本、二进制文件和大文件；指向项目外的符号链接必须不可打开。
15. 分别打开 Vue、React、uni-app、Maven、Gradle 项目，确认项目类型和任务识别正确；取消任务时不得执行，确认后在独立 tmux 会话运行。
16. 在 Claude Code 和 Codex 的授权界面验证“确认当前选项”必须二次确认，“拒绝/返回”发送 Esc，“中断”发送 Ctrl+C；应用不得根据输出自动授权。
17. 分别使用 `user@host`、纯主机/IP 和 `~/.ssh/config` 别名连接；别名中的 ProxyJump 配置应由 OpenSSH 正常应用。输入以 `-` 开头或包含空白的目标必须被拒绝。
18. 在“SSH 公钥管理”中生成 Ed25519 密钥并设置口令；确认页面只展示 `.pub` 公钥，复制内容不包含私钥，`ssh-copy-id` 安装成功后可使用密钥登录。
19. 同时启动前端 dev server 和测试任务，确认二者进入不同的 `mobile-task-*` tmux 会话；在“后台项目任务”中分别重新进入，并确认停止操作必须二次确认且只终止所选任务。
20. 将系统显示大小和字体分别调到默认及最大，在 360dp 级窄屏上检查首页“开发工具”三行双列入口：文字不可被截断、触控目标不小于 48dp、页面可完整滚动且软键盘不遮挡当前输入框。
21. 在终端产生包含中文、大小写英文、超长单行和超过 1 MB 的输出；验证“搜索终端输出”大小写不敏感、结果可滚动选择复制，并明确提示最近 1 MB/100 条限制且不发生 ANR。

## 恢复与预览

1. 锁屏 30 分钟后从通知返回，终端会话仍可用；若 TCP 被系统回收，可一键恢复 tmux。
2. Wi-Fi 与蜂窝网络切换后重新进入工作区，远端 tmux 中的任务和输出仍存在。
3. 启动 Vite/React/uni-app H5 服务，建立 `127.0.0.1` SSH 隧道并用浏览器访问。
4. 使用 `ss`/ADB 验证手机转发端口未监听 `0.0.0.0`。
5. 配置已占用的本地端口，确认 `ExitOnForwardFailure` 明确报错而非假装成功。

## 稳定性与安全

1. 连续输出 50 MB，不崩溃、不 ANR，Ctrl+C 可响应。
2. Claude Code、Codex、Vim 等全屏 TUI 的中文宽字符、真彩和窗口 resize 正确。
3. 检查 logcat：不得出现提示词、密码、私钥或 Token 原文。
4. APK 证书 SHA-256 必须为
   `6F:06:4D:DF:D9:19:97:F6:37:CB:CD:63:38:C3:F1:26:57:F4:C3:64:34:A3:67:B6:30:80:9A:1D:86:C7:C0:35`。
5. 卸载重装前验证备份提示；确认卸载会删除应用私有 Linux 环境。

任何失败均记录：步骤、设备、系统版本、网络、时间、截图/录屏、脱敏 logcat 和复现频率。
