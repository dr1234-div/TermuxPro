## P1

- 重构首页信息架构：未连接时聚焦工作区配置，连接后再展示项目工具。
- Claude/Codex 提供新建、继续最近和选择历史会话，不跨项目恢复；Claude 共享账号场景默认新建，禁止静默续接全局最近会话。
- 工作区保存独立连接后策略和指定 tmux 会话名；会话列表展示创建者不可可靠识别时明确标记“归属未知”，不提供自动进入。
- SSH 工作区支持新增、查看、编辑、复制和删除；最近使用与连接状态可见。
- 统一加载、空、错误、成功状态与可操作修复建议。
- 改造终端顶栏，满足 320–360dp、200% 字体和 48dp 触控目标。
- 200% 字体工具栏已为远程文件、文件预览、项目任务、连接诊断、Git 修改、SSH 密钥和 tmux 会话保留导航/操作空间，并增加 205dp 窄屏布局测试；工作区三按钮文字裁切另行持续审计。
- 建立可控 SSH fixture 与 Android UI 自动化，覆盖 tmux 有/无和网络异常。
- GitHub Runner 模拟器每日/按 UI PR 运行 360dp 深色默认字体与 200% 字体截图回归，本地共享服务器不启动模拟器。
