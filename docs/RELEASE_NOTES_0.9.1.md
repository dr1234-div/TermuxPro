# TermuxPro 0.9.1 正式版发布说明

`0.9.1` 是 `0.9.0` 之后的体验补丁稳定版，来自已发布并通过门禁的 `0.9.1-rc.1` 候选范围。
本版本不加入新的未验证功能，重点补强远程 AI CLI、tmux/Git 可视化管理和发布治理这些 TermuxPro
增值服务。

## 主要变化

- tmux 会话中心细分归属状态：当前工作区、其他工作区、其他 TermuxPro 使用者、归属标记不完整和未标记
  会话分开提示；非当前工作区会话只允许显式进入，不提供重命名或停止。
- Claude Code/Codex CLI 启动前展示当前远端目标；配置不完整时明确提示，避免共享账号或多项目场景下
  误进入错误服务器、错误目录或错误历史会话。
- Git 工作台首屏展示 `host:port · path`，用户在查看分支、修改、提交、同步前能确认当前操作属于哪台
  远端机器和哪个项目。
- 自动 PR/Actions 治理补充单一控制器和失败噪声复核：区分真实 failure、并发取消和替代成功 run，减少
  无效失败提醒。
- 产品范围继续收敛在 TermuxPro 增值服务；Termux 原始终端、PTY、包管理、本地 shell、基础会话和
  基础快捷键只作为不受影响回归面。

## 验收重点

1. 远程 tmux 会话列表必须明确展示会话归属，不允许对非当前工作区会话执行写操作。
2. Claude/Codex 快捷启动必须先展示当前远端目标；历史入口仍只打开 CLI 原生选择器。
3. Git 工作台必须在首屏展示远端主机、SSH 端口和项目路径；既有 Git 操作不回退。
4. Actions 失败提醒必须能追溯到真实 failure、并发取消或替代成功 run。
5. 稳定 Release 必须完成签名 APK 构建、覆盖升级、运行时冒烟和 GitHub Release 创建。

## 已知限制

- 本版本仍不解析 Claude Code/Codex 的私有历史元数据，也不展示跨用户历史内容；历史选择继续交给 CLI
  原生选择器。
- 远程 tmux 的归属判断依赖 TermuxPro 写入的 owner 元数据和运行时校验；归属未知或标记不完整时安全降级。
- 真实手机输入法、厂商 ROM 和弱网场景仍需要持续采样；当前稳定门禁以 GitHub Actions 隔离模拟器和
  自动化回归为主。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.9.0` 正式版或 `0.9.1-rc.1` 候选版，可直接覆盖升级到本正式版本。
