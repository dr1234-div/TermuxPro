# TermuxPro 0.9.3 正式版发布说明

`0.9.3` 是 `0.9.2` 稳定标签发布失败后的修复版。`0.9.2` 标签已推送，但 Release workflow 在覆盖升级
验收脚本的启动等待判定上出现假阴性，公开稳定 Release 未创建；本版本不移动、不覆盖该标签，而是修复
发布门禁后递增版本重新发布。

## 主要变化

- 沿用 `0.9.2-rc.1` 已验证的用户功能范围：AI CLI 终端入口/目标提示、tmux 当前工作区优先展示与操作
  边界提示、Git 单文件暂存管理。
- 修复 Release 覆盖升级验收脚本：显式启动 `com.termux/.app.WorkspaceActivity`，等待进程稳定出现，并
  记录启动输出、进程等待过程、前台 Activity、窗口层级、包信息和 logcat。
- 发布脚本失败时提供可复核证据，避免应用已经启动但 `pidof` 短暂未返回时误判为启动失败。

## 验收重点

1. 稳定版 APK 必须完成 `0.9.1 → 0.9.3` 覆盖升级验收。
2. 启动验收必须证明 Launcher Activity 可启动、进程可稳定检测、无 AndroidRuntime fatal。
3. Release 必须是非草稿、非预发布，附件包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
4. 用户功能范围仍以 `0.9.2-rc.1` 为准，不把 Termux 原始能力作为本轮新增功能。

## 已知限制

- `v0.9.2` 标签保留为失败发布证据，不提供公开稳定 Release。
- 本版本应用行为与 `0.9.2` 稳定准备范围一致，主要差异是发布门禁和版本号。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.9.1` 正式版或 `0.9.2-rc.1` 候选版，可直接覆盖升级到本正式版本。
