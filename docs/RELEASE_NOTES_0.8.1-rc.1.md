# TermuxPro 0.8.1-rc.1 候选版发布说明

`0.8.1-rc.1` 是 `0.8.0` 之后的候选版本，重点处理真实体验反馈中的终端滚动、会话管理、
Claude/Codex 启动安全提示，以及 GitHub 自动化失败邮件噪声。

## 核心变化

- 终端触摸滚动增加明确模式：默认保护 shell 输入，手机上下滑动优先查看历史输出；在 Claude/Codex、
  vim、less 等需要内部滚动的 TUI/AI 场景，可从终端工具箱切换为“AI/TUI 面板”模式。
- 终端会话侧栏补齐本地会话管理：支持关闭当前会话；长按会话行可切换、重命名或关闭指定本地会话。
  关闭操作只影响本地 Termux 会话，不触碰远程 tmux。
- 终端会话反馈不再出现空白 Toast 或 `null - exited`，切换/结束提示至少包含可识别会话信息。
- Claude Code/Codex CLI 启动弹窗补充上下文：默认新建会话，历史入口只打开 CLI 原生选择器；
  共享 Claude 账号场景明确推荐新建，TermuxPro 不自动进入最近会话。
- 自动 PR 流程减少重复失败邮件：预合并 CI/UI 失败时保留 PR 等待修复，但自动 PR workflow 不再跟随
  重复标红；权限、合并后 CI、候选 Release 等真实风险仍保留 failure。
- 新增推送前冒烟门禁：根据相对 `origin/dev` 的变更类型自动补跑相关 Robolectric smoke 测试，减少
  “远端 CI 首次发现断言不匹配”导致的失败邮件。

## 验收重点

1. 手机终端长输出可以用手指查看历史；进入 Claude/Codex/vim/less 等场景时，可从工具箱切换滚动模式。
2. 终端侧栏能清楚找到本地会话关闭入口；关闭确认文案说明不会停止远程 tmux。
3. 长按会话行后，切换、重命名、关闭三个动作清晰可区分；危险动作不和普通操作同层级误触。
4. Claude/Codex 快捷启动不会静默续接最近历史；共享 Claude 账号默认新建会话。
5. GitHub Actions 新增失败时，维护者能区分真实 CI 失败、自动 PR 等待状态和外部 App 空检查噪声。
6. 360dp 深色主题、默认字体和 200% 字体下，终端工具箱、会话侧栏和 AI 启动弹窗仍可读、可操作。

## 已知限制

- 本版本仍不解析 Claude Code/Codex 的历史会话元数据，也不展示跨用户历史内容；历史选择仍交给 CLI
  原生选择器。
- 终端滚动手感已通过模拟器和策略测试覆盖，但真实手机输入法、厂商 ROM 和高刷滚动手感仍需要持续采样。
- 远程 tmux 会话管理仍遵循归属隔离；归属未知或其他用户会话只允许显式进入，不提供越权重命名/停止。
- GitHub 外部 App 的 queued 空 check suite 不是本仓库 Actions 失败；若未来被设为必需检查，需单独治理。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.8.0` 正式版，可直接覆盖升级到本候选版本。
