# TermuxPro 0.5.0-rc.1 候选版发布说明

`0.5.0-rc.1` 聚焦 0.4.0 正式版后的手机端真实使用体验：减少首页干扰、增强终端内工具可发现性、降低共享
tmux 环境误入风险，并修复设置页危险色误导。

## 核心变化

- 首页继续瘦身：主操作改为“打开远程终端”，连接配置与低频工具不再平铺干扰首次进入。
- 终端顶栏工具入口从纯图标改为文字“工具箱”，降低首次发现成本。
- 工具箱按“当前上下文 / 项目与 Git / AI 安全操作 / 键区切换”分组，不再是无层级长列表。
- tmux 会话列表新增创建时间和最近活跃时间，帮助用户在共享服务器上判断是否应进入某个会话。
- tmux 枚举改为按 `session_id` 查询字段，避免未知会话名包含冒号时被误解析。
- 设置页改用 TermuxPro 产品主题，不再继承上游红色主色；危险色继续只用于破坏性动作或明确故障。
- 继续保持 Claude Code / Codex CLI 默认新建或显式历史选择，不自动进入共享上下文。

## 验收重点

1. 从首页到远程终端的路径是否更短、更明确。
2. 终端里是否能直接发现“会话 / 工作台 / 工具箱”三个关键入口。
3. 工具箱分组是否符合开发者当下任务，而不是让用户在长列表里猜。
4. tmux 列表是否能帮助判断会话新旧、活跃程度和归属状态。
5. 设置页顶部是否不再呈现危险红色。
6. 未知归属 tmux 会话仍不得被 TermuxPro 重命名或停止。

## 已知限制

- 本候选版不新增统一的 Claude/Codex 历史元数据中心，历史恢复仍使用各自 CLI 原生选择器。
- Android 实体设备或云真机上的软键盘、弱网、后台恢复及 OEM 行为仍需在后续版本继续补充证据。
- 候选版用于体验验证；若发现 P0/P1 问题，将修复后递增候选编号，不覆盖既有标签。

## 安装提醒

- 包名保留为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 卸载应用会删除其私有 Linux 环境和本地配置，升级体验前请备份重要数据。
- 如果你已经安装 `0.4.0` 正式版，可直接覆盖升级到本候选版。
