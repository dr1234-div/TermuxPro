# TermuxPro 0.9.0 正式版发布说明

`0.9.0` 是 `0.8.1` 之后的稳定版，发布范围来自已通过门禁的 `0.9.0-rc.3` 候选版。

## 核心变化

- 终端工具箱增值入口继续收敛在远程开发场景：Git、tmux、项目任务、远端文件、Web 预览、环境诊断、
  SSH 密钥等低频工具不堆在首页，按需从开发上下文进入。
- Claude Code 启动提示明确共享账号风险，新建会话是安全默认；历史恢复必须由用户进入 Claude
  原生选择器后显式选择。
- Codex CLI 启动提示明确当前项目确认，不自动进入最近历史会话，避免污染错误项目上下文。
- 候选/正式发布链路补齐 Release 页面兜底、设备验收空输出诊断和回归，减少失败邮件噪声并保留真实
  失败证据。
- 产品边界明确：Termux 原本已有终端、PTY、包管理、本地 shell、基础会话和基础快捷键能力只做
  “不受影响”回归守护，不作为 TermuxPro 主线研究或重造方向。

## 验收重点

1. 稳定 Release 必须完成签名 APK 构建、覆盖升级、运行时冒烟和 GitHub Release 创建。
2. `v0.9.0` 必须是非草稿、非预发布，附件包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
3. 终端原始能力不因 TermuxPro 增值入口受到破坏。
4. AI CLI 与远程工作区相关提示沿用 rc.3 已验证策略。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.8.1` 正式版或 `0.9.0-rc.3` 候选版，可直接覆盖升级到本正式版本。
