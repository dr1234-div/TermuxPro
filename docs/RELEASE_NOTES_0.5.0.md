# TermuxPro 0.5.0 正式版发布说明

`0.5.0` 是 0.4.0 后的体验优化正式版，聚焦手机 SSH 远程开发的入口效率、终端内工具可发现性、
tmux 会话判断信息和发布治理稳定性。本版本沿用 `0.5.0-rc.1` 的功能冻结范围，并加入外部 GitHub
App 空检查噪声诊断，避免把第三方 check suite 误判为 TermuxPro 自身 Actions 失败。

## 核心变化

- 首页继续瘦身：主操作改为“打开远程终端”，连接配置与低频工具不再平铺干扰首次进入。
- 终端顶栏工具入口从纯图标改为文字“工具箱”，降低首次发现成本。
- 工具箱按“当前上下文 / 项目与 Git / AI 安全操作 / 键区切换”分组，不再是无层级长列表。
- tmux 会话列表新增创建时间和最近活跃时间，帮助用户在共享服务器上判断是否应进入某个会话。
- tmux 枚举改为按 `session_id` 查询字段，避免未知会话名包含冒号时被误解析。
- 设置页改用 TermuxPro 产品主题，不再继承上游红色主色；危险色继续只用于破坏性动作或明确故障。
- 继续保持 Claude Code / Codex CLI 默认新建或显式历史选择，不自动进入共享上下文。
- 新增 GitHub check suite 诊断脚本，区分外部 App 空检查噪声和仓库自身 Actions 门禁风险。

## 验收结论

- `v0.5.0-rc.1` 已通过完整 CI、模拟器 UI、merge commit 收尾 CI 和签名 APK 覆盖升级发布门禁。
- `0.5.0` 正式版沿用同一产品功能冻结范围，`versionCode=50002`，高于 `0.5.0-rc.1` 的 `50001`。
- 当前 `dev` 上 GitHub Actions check suite 无风险；`vercel`、`4everland`、`cursor` 的空 check suite
  被识别为外部集成噪声，未设置为必需检查，不阻断发布。
- 正式 Release 仍会在发布前执行签名 APK 覆盖升级、Launcher/桌面名称、进程和 AndroidRuntime 冒烟验证。

## 已知限制

- TermuxPro 只管理带有匹配 ownership 元数据的自有会话，不会接管既有共享 tmux 会话。
- Claude Code 与 Codex CLI 历史会话仍使用各自原生选择器，统一 AI 会话元数据中心尚未完成。
- Android 实体设备或云真机上的软键盘、弱网、后台恢复及 OEM 行为仍需在后续版本继续补充证据。

## 安装提醒

- 包名保留为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 卸载应用会删除其私有 Linux 环境和本地配置，升级体验前请备份重要数据。
- 如果你已经安装 `0.5.0-rc.1`，可直接覆盖升级到本正式版。
