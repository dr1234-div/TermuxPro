# TermuxPro 0.9.6 正式版发布说明

`0.9.6` 沿用 `0.9.6-rc.1` 已通过候选门禁的冻结范围，不加入新的未验证功能。本版本继续聚焦
TermuxPro 增值服务：手机 SSH 远程开发、AI CLI 会话启动、Git 可视化管理、深色移动端界面和自动发布
稳定性。

本版本不重做 Termux 原始终端、PTY、包管理、本地 shell、基础会话、基础快捷键或基础文件能力；这些
能力仅作为“不被增值层破坏”的兼容回归面。

## 主要变化

- SSH 目标输入支持从手机直接粘贴常见格式：`user@host`、`user@host:port`、`ssh -p port user@host` 和
  `ssh://user@host:port/path`；保存、连接、Git、tmux、文件、诊断、SSH Key 和 Web 预览统一标准化目标。
- AI CLI 会话中心从说明页升级为行动中心：直接提供 Claude/Codex 新建与历史入口，历史入口只打开 CLI
  原生选择器，不读取私有历史，也不自动进入最近会话。
- AI 会话中心新增“查看 Git 改动”：用户在 Claude/Codex 修改代码后，可直接进入结构化 Git 工作台概览。
- 深色产品页弹窗进一步统一为 TermuxPro 样式，并增加静态门禁，防止系统默认黑字/浅色列表在深色页面
  中再次出现。
- 自动研发 PR 合并流程避免等待自身检查，减少成功合并后仍出现失败/超时邮件的噪声。

## 验收重点

1. 稳定版 APK 必须完成 `0.9.5 → 0.9.6` 覆盖升级验收。
2. 粘贴 SSH 目标后必须只产生规范化 host/port/path，不执行粘贴内容中的额外命令。
3. AI CLI 会话中心启动 Claude/Codex 时必须打开独立 SSH 终端，并固定普通 `ssh_only` 策略，不自动进入、
   创建或恢复 tmux。
4. Claude 共享账号场景下默认新建会话；历史选择只进入 Claude 原生选择器。
5. “查看 Git 改动”只能打开结构化 Git 工作台，不能向当前 shell 注入 Git 命令。
6. Release 必须是非草稿、非预发布，附件包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
7. 原始 Termux 终端、PTY、本地 shell、基础会话和基础快捷键语义不得被 TermuxPro 增值层修改。

## 已知限制

- 本版本仍不读取 Claude/Codex 内部历史文件；历史列表由 CLI 原生选择器负责。
- Git 工作台不替代完整 Git 客户端，仍以移动端高频安全操作为主。
- 本地共享服务器 KVM 不可用，稳定 APK 的覆盖升级与截图验收依赖 GitHub Runner 模拟器。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.9.5` 正式版或 `0.9.6-rc.1` 候选版，可直接覆盖升级到本正式版本。
