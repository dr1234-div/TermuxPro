# TermuxPro 0.7.0 正式版发布说明

`0.7.0` 是 Git 工作台操作闭环正式版，沿用 `0.7.0-rc.1` 已验证的冻结范围，不新增未经过候选门禁的
应用功能。该版本面向手机 SSH 远程开发中的日常 Git 同步链路：查看状态、暂存、提交、刷新远端、
快进拉取和安全推送。

## 核心变化

- Git 工作台支持“提交已暂存”：提交前展示已暂存/未暂存范围，只创建本地提交，不自动暂存、不推送、
  不丢弃文件。
- Git 概览展示具体 upstream 名称，并支持“更新远端”：只 fetch 当前 upstream 所属远端，不 merge、
  不 rebase、不修改工作树或 index。
- Git 工作台支持“快进拉取”：仅在工作树干净、存在 upstream 且当前分支落后时执行 `git pull --ff-only`。
- Git 工作台支持“推送”：仅对当前分支已配置的 upstream 执行普通非 force push；游离 HEAD 或仍落后
  upstream 时阻止，推送成功后刷新本地远端跟踪状态。
- 发布自动化避免稳定证据补录分支误触发候选发布。

## 验收重点

1. 远程 Git 仓库概览能展示当前分支、upstream、领先/落后、已暂存/未暂存数量。
2. 已暂存文件可创建本地提交；未暂存文件不会误纳入提交。
3. fetch、pull、push 三类同步动作都有清晰启用条件和失败提示。
4. pull 不执行 merge/rebase；push 不执行 force，不创建新远端分支。
5. 游离 HEAD、无 upstream、落后 upstream、脏工作树等异常路径不会误报成功。
6. 360dp 深色主题、默认字体和 200% 字体下，Git 工作台状态、按钮和弹窗可读、可点击。

## 已知限制

- 仍不支持按单个文件暂存/取消暂存、stash、冲突解决、远端分支删除或强制推送。
- 推送仅面向已配置 upstream 的当前分支；新建远端分支需要后续独立设计确认流程。
- Git 操作依赖远端项目路径、SSH 认证和服务器上的 Git 可用；认证失败、非 Git 仓库或网络中断会失败关闭。
- Claude Code/Codex CLI 历史会话统一管理、tmux 更细粒度 CRUD 和多设备运行时证据仍在后续迭代范围内。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.6.0` 正式版或 `0.7.0-rc.1` 候选版，可直接覆盖升级到本正式版。
