# TermuxPro 0.9.0-rc.2 候选版发布说明

`0.9.0-rc.2` 是 `0.9.0-rc.1` 之后的候选修订版，不扩大 0.9.0 发布列车范围，只补齐候选发布流程和
AI CLI 使用前的上下文理解问题。

## 核心变化

- 修复候选 Release 已成功后，自动 PR 流水线仍可能等待到超时的问题。后续候选发布会同时核对 Release
  workflow 和 GitHub Release 页面/附件，避免“实际已发布但流水线失败”的噪声。
- Claude Code 启动弹窗新增共享账号风险提示，明确新建会话是安全默认，历史恢复必须由用户在 Claude
  原生选择器中手动选择。
- Codex CLI 启动弹窗新增当前项目确认提示，继续保证 TermuxPro 不自动进入最近历史会话。
- 继续遵守增值服务边界：本版本只打磨远程 AI 开发体验和发布稳定性，不研究或重做 Termux 原始终端能力。

## 验收重点

1. 启动 Claude Code 时，用户能在弹窗正文看到共享账号风险说明。
2. 启动 Codex CLI 时，用户能在弹窗正文看到当前项目确认和不自动进入最近会话说明。
3. 新建 AI 会话与选择历史会话的命令策略保持不变。
4. 候选 Release 自动化不因已成功发布的 Release 页面和附件而继续空等。
5. GitHub CI、模拟器 UI、dev 收尾 CI 和 Release workflow 均成功。

## 已知限制

- 仍不解析 Claude Code/Codex 历史会话元数据；历史恢复继续交给 CLI 原生选择器。
- 本地共享服务器不启动 Android 模拟器；运行时证据来自 GitHub Actions 隔离模拟器和 Release workflow。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.8.1` 正式版或 `0.9.0-rc.1` 候选版，可直接覆盖升级到本候选版本。
