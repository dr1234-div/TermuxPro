# TermuxPro 0.9.5-rc.1 候选版发布说明

`0.9.5-rc.1` 是 `0.9.4` 之后的候选体验版，冻结范围只包含 TermuxPro 增值服务改进：
远程 AI 会话中心、Git 工作台增强和快捷指令安全模板。本版本不研究、不重做 Termux 原始终端、PTY、
包管理、本地 shell、基础会话、基础快捷键或基础文件能力；这些能力仅作为“不被增值层破坏”的回归面。

## 主要变化

- 新增 AI CLI 会话中心：在工具箱内集中展示当前工作区、Claude/Codex 新建与历史选择命令预览、
  共享账号风险和相关入口，减少在手机终端里手动回忆命令。
- Git 工作台新增安全 Stash 管理：可保存当前改动、查看 stash 列表、在干净工作区应用指定 stash、
  删除指定 stash；不执行 `git stash pop`、`git stash clear`、提交或推送。
- Git 分支切换增加脏工作区门禁：当前有未提交改动时，UI 直接阻止切换并提示先 stash/提交/处理；
  命令层也返回 77，避免误切分支污染远程开发上下文。
- 快捷指令模板移除 Claude 静默续接最近会话：不再提供 `claude --continue` 模板；Claude 模板明确
  区分“新建独立会话”和“选择历史会话”，历史入口只交给 CLI 原生选择器。
- 继续强化增值服务边界：Termux 原有基础能力只做兼容守护，研发资源优先投入远程工作区、AI CLI、
  tmux/Git 可视化、自定义快捷指令、移动端工作流和工具箱体验。

## 验收重点

1. AI CLI 会话中心不得读取 Claude/Codex 私有历史文件，也不得自动进入最近会话。
2. Git Stash 操作必须只作用于用户选择的当前远程工作区，不提交、不推送、不清空全部 stash。
3. 分支切换和远端跟踪分支创建在脏工作区必须被阻止，且当前工作树保留。
4. Claude 快捷指令模板不得出现 `claude --continue`，共享账号默认新建独立会话。
5. 360dp、默认字体和 200% 字体下关键页面保持可读和可操作。
6. 原始 Termux 终端、PTY、本地 shell 和基础会话语义不得被 TermuxPro 增值层修改。

## 已知限制

- 本候选版不展示 Claude/Codex 内部历史列表；历史选择仍由 CLI 原生选择器负责。
- Git Stash 当前只支持保存、查看、应用和删除，不支持跨工作区迁移或可视化冲突解决。
- 本地共享服务器 KVM 不可用，模拟器 UI 验收依赖 GitHub Runner。
