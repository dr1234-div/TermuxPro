# TermuxPro 0.4.0-rc.1 候选版发布说明

这是 `0.4.0` 的首个候选版本，重点补齐远程 tmux 会话的安全生命周期管理，并继续降低手机端远程开发的操作成本。
候选版用于安装体验和运行时回归，不代表稳定版门禁已经全部通过。

## 主要改进

- tmux 会话中心支持新建、进入、重命名和停止，形成完整生命周期。
- 新建会话绑定当前服务器、项目目录和 TermuxPro ownership；同名冲突会明确失败，不覆盖已有会话。
- 未知归属的共享 tmux 会话保持只读，只允许进入，避免误删或污染其他用户工作。
- 重命名和停止前重新核验 owner、工作区指纹及 tmux 实例身份，归属变化时失败关闭。
- 危险“停止会话”从普通操作中独立并标红，确认页明确展示会话名、服务器、端口、目录和影响范围。
- 写操作期间锁定列表并展示具体进度；网络结果不确定时要求刷新核对，避免盲目重复提交。
- 会话名称统一采用可移植字符集，禁止会被 tmux 静默改写的点号以及 Shell 特殊字符。

## 自动化证据

- 隔离真实 SSH/tmux fixture 覆盖新建、重命名、停止、同名冲突、源会话消失、归属变化和旁观会话保护。
- Android 35、360dp、深色主题、简体中文默认字体与 200% 字体截图覆盖列表、新建、重命名和停止确认弹窗。
- PR #42 的完整 CI 与模拟器 UI 门禁通过；PR #44、#45 进一步验证自动 PR、门禁合并和 merge commit 收尾 CI。
- 发布标签仍须重新执行 Release/R8、ARM64 ABI、签名、版本、APK 内容和证书指纹校验。

## 体验重点

1. 多个远程工作区之间的会话是否严格隔离，目标服务器、端口和目录是否始终清晰。
2. 自有会话能否安全新建、重命名和停止；共享会话是否始终没有写操作。
3. 弱网或远端状态变化时，失败提示是否能阻止重复危险操作并引导刷新核对。
4. 默认字体与 200% 字体下，新建、重命名和停止确认弹窗是否完整可读、按钮可达。
5. 从 `0.2.0` 稳定版覆盖升级后，应用名、UID、工作区配置和本地 Linux 环境是否保持。

## 已知限制

- TermuxPro 只能管理带有匹配 ownership 元数据的自有会话，不会接管既有共享 tmux 会话。
- 会话列表暂未把 pid/session_id/created 固化为点击快照；执行写操作时会重新解析并校验当前实例。
- Claude Code 与 Codex CLI 历史会话仍使用各自原生选择器，统一 AI 会话元数据中心尚未完成。
- Android 实体设备或云真机上的软键盘、弱网、后台恢复及 OEM 行为仍需按风险矩阵补充证据。

## 安装提醒

- 包名保留为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 卸载应用会删除其私有 Linux 环境和本地配置，升级体验前请备份重要数据。
- 本版本是 Pre-release；需要稳定环境时继续使用 `0.2.0`。
