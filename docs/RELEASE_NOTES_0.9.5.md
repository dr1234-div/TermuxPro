# TermuxPro 0.9.5 正式版发布说明

`0.9.5` 沿用 `0.9.5-rc.1` 已通过候选门禁的冻结范围，不加入新的未验证功能。本版本继续聚焦
TermuxPro 增值服务：手机 SSH 远程开发、AI CLI 会话启动、Git 可视化管理、自定义快捷指令和移动端
工具箱体验。

本版本不重做 Termux 原始终端、PTY、包管理、本地 shell、基础会话、基础快捷键或基础文件能力；这些
能力仅作为“不被增值层破坏”的兼容回归面。

## 主要变化

- 新增 AI CLI 会话中心：集中展示当前工作区、Claude/Codex 新建与历史选择命令预览，并提示共享账号、
  tmux 和当前可见终端风险。
- Git 工作台新增 Stash 管理：支持保存、查看、应用和删除指定 `stash@{N}`；不提供清空全部 stash、
  pop、commit 或 push 等高风险快捷动作。
- Git 分支切换补强脏工作区门禁：本地分支切换和远端跟踪分支创建前都会检测未提交修改，脏工作区直接
  阻止并提示先 stash、提交或处理改动。
- Claude 快捷指令模板移除 `claude --continue`，区分“新建独立会话”和“历史选择器”，避免共享账号下
  静默续接最近会话污染其他项目上下文。
- 项目规则继续收紧增值服务边界：Termux 原本已有基础能力只做兼容守护，不进入主线需求研究或重造队列。

## 验收重点

1. 稳定版 APK 必须完成 `0.9.4 → 0.9.5` 覆盖升级验收。
2. AI CLI 历史入口只能进入 CLI 原生选择器，TermuxPro 不自动进入最近会话。
3. Git Stash 删除只能作用于用户显式选择的 `stash@{N}`。
4. 脏工作区不得静默切换分支或创建远端跟踪分支。
5. Release 必须是非草稿、非预发布，附件包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
6. 原始 Termux 终端、PTY、本地 shell、基础会话和基础快捷键语义不得被 TermuxPro 增值层修改。

## 已知限制

- 本版本不读取 Claude/Codex 私有历史文件，也不展示 CLI 内部历史列表；历史选择仍交给 CLI 原生选择器。
- Git Stash 工作台不支持一键 pop、清空全部 stash、提交或推送，避免手机端误操作造成数据损失。
- 本地共享服务器 KVM 不可用，发布前 Android 覆盖升级验收依赖 GitHub Runner 模拟器。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.9.4` 正式版或 `0.9.5-rc.1` 候选版，可直接覆盖升级到本正式版本。
